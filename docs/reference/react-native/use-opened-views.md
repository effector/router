# useOpenedViews

Returns the route views that are currently open.

`useOpenedViews` is re-exported from `@effector/router-react`; its API and behavior are identical in React Native.

## Import

```tsx
import { useOpenedViews } from '@effector/router-react-native';
```

## Original documentation

See [useOpenedViews in the React API](/react/use-opened-views) for usage and examples.
