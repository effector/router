# useIsOpened

Returns whether a route is currently open.

`useIsOpened` is re-exported from `@effector/router-react`; its API and behavior are identical in React Native.

## Import

```tsx
import { useIsOpened } from '@effector/router-react-native';
```

## Original documentation

See [useIsOpened in the React API](/react/use-is-opened) for usage and examples.
